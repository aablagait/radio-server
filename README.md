# Моё радио

Личное онлайн-радио: один непрерывный поток MP3, все слушатели слышат один и тот же момент трека одновременно — как настоящее FM-радио. Плюс раздел "Далее в эфире" — что играет сейчас и что будет дальше, с возможностью скачать треки.

## Что нужно установить

1. **Python 3.10+**
2. **ffmpeg** — обязательно, он кодирует и вещает звук.
   - Windows: скачать с https://ffmpeg.org/download.html и добавить в PATH
   - macOS: `brew install ffmpeg`
   - Linux: `sudo apt install ffmpeg`

Проверить, что всё встало: `ffmpeg -version`

## Установка

```bash
cd radio-server
pip install -r requirements.txt
```

## Добавь свои треки

Скопируй файлы (mp3, flac, wav, ogg, m4a, aac) в папку `music/`.
Можно с подпапками — сервер найдёт всё рекурсивно.

Треки играют **по алфавиту**, по завершении списка — снова с начала (по кругу).
Если хочешь другой порядок — переименуй файлы с номерами в начале
(`01 - Track.mp3`, `02 - Track.mp3`, ...), т.к. плейлист строится по сортировке имён.

## Запуск

```bash
python main.py
```

В консоли появится адрес. Сервер слушает на всех интерфейсах, порт **8000**.

- На этом же компьютере: http://localhost:8000
- С другого устройства в той же сети (телефон, другой ПК): http://<IP-этого-компьютера>:8000

Узнать свой локальный IP:
- Windows: `ipconfig` (строка IPv4-адрес)
- macOS/Linux: `ifconfig` или `ip a`

## Разделы сайта

- **`/` — Эфир.** Живой непрерывный поток, все слушатели синхронно слышат один момент.
- **`/library` — Далее в эфире.** Показывает, какой трек играет прямо сейчас и что будет следующим (вычисляется по реальному времени, без возможности что-то запустить вручную), плюс кнопка "Скачать" у каждого трека в очереди — можно скачать файл в оригинальном качестве.

## Добавил новые треки после запуска?

Плейлист собирается один раз при старте. Просто перезапусти сервер
(`Ctrl+C`, потом снова `python main.py`) — он пересоберёт список.

## Как это работает

- `ffmpeg` в режиме реального времени (`-re`) читает и кодирует плейлист в MP3,
  зациклив его (`-stream_loop -1`).
- Сервер на FastAPI читает байты из ffmpeg один раз и рассылает их копии
  всем подключённым браузерам одновременно — поэтому все слышат один и тот же момент.
- Страница `/` — простой плеер с тегом `<audio>`, который сразу подключается к `/stream`.

## Дальше можно докрутить

- Смена битрейта/качества — константа `BITRATE` в `main.py`.
- Плейлисты/категории по папкам — расшир��ть `build_playlist_file()`.
- Публичный доступ из интернета (не только локальная сеть) — понадобится
  проброс порта на роутере или туннель (например, Cloudflare Tunnel).
